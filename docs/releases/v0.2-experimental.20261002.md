## ✨ New in this image

- **Whole Vibemis in black/crimson:** shared dark surfaces across launcher, settings, help, dialogs, popups and existing token-based quick-menu controls. Existing button shapes, fonts, focus and gamepad navigation remain cohesive.
- **Sixteen accents:** Teal, Indigo, Green, Amber, Crimson, Red, Orange, Gold, Lime, Mint, Cyan, Blue, Violet, Pink, Silver and Rose. New preferences default to Crimson; existing saved accents stay intact.
- **Three matching top-bar icons:** local network link/Wi-Fi readout, local battery percentage/charging state, and Vibepollo host CPU/RAM/GPU/VRAM/temperatures/encoder/network hardware stats.
- **Host stats setup:** select a PC, open its hardware button and configure the HTTPS management URL, a read-only token permitting GET `/api/host/stats`, and a verified SHA-256 certificate fingerprint for a self-signed host. GameStream pairing alone does not authorize the management API. Unsupported hosts/sensors show clear errors or N/A. [Full setup and privacy details](https://github.com/th3d3ck3r/Moonlight-OS/blob/main/docs/VIBEMIS_CRIMSON.md).
- **Shorter initial Bluetooth scan:** six seconds instead of twelve, with rescan/retry and the live pairing confirmation agent retained.

Host stats appear in a launcher panel; existing in-stream statistics and quick menus remain intact. This image retains Crimson Apollo animation, all five frontend choices, full Intel iHD decoding, English defaults, native Retina/Openbox handling, Mac volume/display/keyboard-light keys, speaker restore, 100-row console, AirPods A2DP policies and DualSense audio suppression. OS minimization, the separate Crimson Console/Glass plans and a new in-stream host overlay are not included.

## 🎮 Start a frontend and recover

The boot selector offers **1 Vibemis · 2 Artemis · 3 Pegasus · 4 Moonlight · 5 CocoOS**. Enter/eight-second timeout keeps the saved choice; initial default and failure fallback are Moonlight. Settings option 9 reopens the selector, or run `sudo moonlight-os-client vibemis` from tty2 and reboot after ending the stream. Replace `vibemis` with the other client name as needed. Pair the PC separately in each streaming client. Pegasus is a launcher, not a decoder.

Mac tty2: **Control + Option + F2**; return with **Control + Option + F1**, adding Fn when needed. F1/F2 adjust screen brightness; F5/F6 keyboard brightness; F10 mute; F11/F12 volume. Control + Option + Shift + M toggles direct mouse mode during streams. Escape reveals boot details.

Run `moonlight-bluetooth` for generic pairing. Put the device in pairing mode first: SHARE + PS for DualShock 4, CREATE + PS for DualSense, or the AirPods Pro 2 case button. Respond to prompts, and rescan if discovery takes longer than the initial scan.
