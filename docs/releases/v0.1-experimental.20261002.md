## ✨ Included

- **Crimson Apollo animated boot screen:** black/crimson moon, orbiting Apollo-inspired spacecraft, activity lights, masked prompts and text recovery.
- **Remembered boot selector:** Vibemis, Artemis, Pegasus, vanilla Moonlight and CocoOS. Enter/eight-second timeout retains the selected frontend; initial default and launch-failure fallback are vanilla Moonlight.
- **Guided Bluetooth:** scan, pair with live confirmation/PIN agent, verify paired/trusted/connected state, reconnect, disconnect and confirmed forget. No brand filter. Supports controllers using Linux-compatible Bluetooth protocols; proprietary dongle-only devices still need their dongle.
- **All prior repairs retained:** full Intel iHD H.264/HEVC decode stack, dynamic DRM detection, English defaults/CocoOS labels, native Retina/Openbox sizing, stream-only mouse shortcut, speaker save/restore, Mac brightness/volume/keyboard-light keys, 100-row console, AirPods A2DP modes and DualSense audio suppression.

Pegasus is a launcher for the four streaming clients. Vibemis and Artemis store their own host credentials; pair the PC inside each client you use. The planned Crimson Console, Crimson Glass and optional host overlay are not implemented by this release.

## 🎮 Frontends, Bluetooth and Mac keys

At boot choose 1 Vibemis, 2 Artemis, 3 Pegasus, 4 Moonlight or 5 CocoOS. From settings choose option 9, or `sudo moonlight-os-client vibemis` (replace with `artemis`, `pegasus`, `moonlight` or `cocoos`); end the stream and reboot to apply the saved choice.

Run `moonlight-bluetooth` from tty2 for pairing. Put the device in pairing mode first: DualShock 4 uses SHARE + PS, DualSense uses CREATE + PS, and AirPods Pro 2 use the case's pairing button. Select the discovered device and respond to any confirmation prompt. Older `dualsense-pair` and `airpods-pair` commands use the same generic flow.

Mac recovery: Control + Option + F2 (add Fn if needed); return with Control + Option + F1. F1/F2 adjust display brightness, F5/F6 keyboard lighting, F10 mute and F11/F12 volume; add Fn when the keyboard sends ordinary function keys. Control + Option + Shift + M toggles direct mouse mode during a stream. Display/keyboard brightness and volume worked in prior physical testing; repeat during streams and after reboot. Escape reveals boot details; a one-time GRUB `plymouth.enable=0` disables the animation for recovery.

Keep the older repair download available as a fallback. Report boot, frontend selection, animation handoff, controller/AirPods pairing, media keys, English UI, stream size and decode telemetry results when testing the next experimental candidate.
